Local-only showcase of Vulpes, a web desktop for penetration testing. The terminal is a real BusyBox Linux booted in your browser with v86 (WebAssembly) — try ls, uname -a, vi. It has no network, so it is entirely local. The GUI tools (Caido, Wireshark…) only stream live in the full Vulpes; here they explain themselves. Open things from the launcher and drag the windows around.
